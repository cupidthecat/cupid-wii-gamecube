# Compatibility

Commercial gameplay is not verified. Both supplied games have reached file selection and produced nonzero PCM on Windows and Linux. Sunshine accepts Start, movement, jumping and slot A on both platforms; native runs also enter the opening sequence. Galaxy displays a valid pointer and accepts slot input on both platforms. Its native run also creates game-data and banner files through guest filesystem requests and reaches icon selection. Later loading of those files, controllable gameplay and useful playback speed remain unverified. These observations use private local dumps. Initial captures used development snapshots based on `c37e83160ce7`; that revision identifies their baseline. Later captures identify the integrated checkpoint where its content was preserved. Executables print their configured revision in `--version` and final state, so a revision set before later compilation must be interpreted with the recorded source snapshot.

## Recording a new result

Record the source revision and working-tree status, platform/compiler, graphics and audio backend, console, input mapping, user-data conditions, run bounds, final state, and visible behavior. Keep private traces local.

Use separate milestones: apploader completed, title screen reached, gameplay reached, and playable. Playable requires rendered gameplay, usable controls, audio, and demonstrated save/load behavior. A frame count or successful bounded exit alone is insufficient. Sanitizer, package, and helper comparisons validate their named paths; they do not establish a game's playability.
