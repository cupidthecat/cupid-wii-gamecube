# Implementation milestones

The goal is playable gameplay in both supplied games on Windows and Linux. Every milestone needs executable behavior and a repeatable test.

| Slice | Current evidence | Next completion condition |
| --- | --- | --- |
| Build and packages | Native MSVC, Linux GCC/Clang, sanitizer builds, public suites, and extracted CLI packages have passed intermediate snapshots. | Repeat all checks on the final integrated revision and publish artifacts only when authorized. |
| Interpreter and memory | Integer/FPU/paired/MMU/cache fixtures pass; estimate and fused helpers have direct bit comparisons. Full memory/cache callers compare CPU mirrors, bounded host spans, rejected PTE backing writes and cache replacement. An 8,192-step authored comparison matches complete CPU states, ordered bus records and RAM images. Cache acceleration retains pinned replacement behavior. | Broader instruction/state differential execution, data-cache visibility, measured execution acceleration, and appropriate redistributable hardware tests. |
| Disc and executable boot | Both RVZ discs' decoded reads, filesystems, and metadata were compared directly. Both apploaders complete and both games reach file selection on Windows and Linux. | Complete defined boot/system-data behavior and continue normal guest execution into gameplay. |
| Devices and storage | Synthetic interrupt/DMA/VI/SI/EXI/card/IOS fixtures pass, including overlapping card completion and actual startup-fault regressions. A fresh native Galaxy run reads its copied guest-created save exactly and opens the restored Mario slot. | Validate gameplay save creation, persistence, reopening, and interrupt timing in both games. |
| Graphics | Commands, transforms, textures, TEV, EFB access and copies have focused and direct comparisons. OpenGL fragment rendering matches exact CPU output on RTX 3060 and Mesa, including guest-driven copy/clear/VI paths. Both bounded commercial GPU runs match software state, frame and storage results. | Broaden GPU coverage and measured performance; resolve remaining defined pixel behavior and geometry; verify real guest gameplay rendering. |
| Audio | DSP protocol/mixing comparisons and guest PCM-to-audio-DMA fixtures pass. Both games generate nonzero PCM on both platforms. Full host-mixer comparisons and a native synthetic endpoint loopback pass; standalone authentication tasks preserve tested audio/task transitions. | Verify gameplay audio in both games, audio timing, commercial-game host playback and the live Linux output endpoint. |
| Wii services and input | Title context, FS/ES/DI, network clock/configuration, Bluetooth/HID transport, host motion mapping, and deterministic input replay have executable tests. Exact settled camera projection passes both platforms. Galaxy's Linux raw-IR replay visibly supplies pointer input, hover and accepted slot selection. | Cross-platform game acceptance of live Remote/Nunchuk/IR/motion input and controllable gameplay. |
| Commercial playability | Both games reach file selection on Windows and Linux. Native Sunshine enters the opening aircraft/airstrip sequence. Native Galaxy reloads its Mario slot and advances through Play to the opening storybook. Longer normal-input probes continue. | Rendered gameplay, audio, working controls, save/load and full-speed demonstrations in both games on both platforms. |

Continue from the first real divergence after each fix. Preserve unrelated work and private assets. Public CI must remain independent of console dumps and commercial discs.
